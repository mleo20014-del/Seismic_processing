- [ ] Логика запуска: проверка наличия проектов
- [ ] LaunchScreen (QDialog) — модальное окно

- [ ] Структура папок (auto-create при старте)
- [ ] Toolbar с кастомным ModeTabBar для вкладок режимов

- [ ] Восстановление активных вкладок из сессии
- [ ] Диалог "Сохранить?" при закрытии вкладки

- [ ] ConnectionManager — ping и статус

- [ ] Блокировка Training/Processing если офлайн

- [ ] Кастомный ModeTabBar в toolbar
- [ ] Максимум 4 вкладки (одна на режим)

- [ ] Кнопка × на каждой вкладке
- [ ] Диалог сохранения при закрытии вкладки

- [ ] Форма параметров генерации

- [ ] Форма гиперпараметров (lr, epochs, batch_size)

- [ ] WebSocket мониторинг loss в реальном времени
