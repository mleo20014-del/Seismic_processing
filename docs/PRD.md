# PRD — DeGhost With AI
**Product Requirements Document**

## Обзор проекта
Научный десктопный инструмент для подавления кратных волн
в сейсмических данных с использованием U-Net нейросетей.
Вычисления выполняются на удалённом GPU-сервере.
Интерфейс — PyQt6 десктопное приложение на Windows.

## Стек технологий
- Python 3.12+
- PyQt6 — десктопный интерфейс
- PyTorch — U-Net модели
- NumPy, SciPy — обработка данных
- h5py — работа с HDF5
- segyio — работа с SEG-Y
- FastAPI — серверный API (удалённый сервер)
- requests, websockets — клиент серверного API
- pyqtgraph — высокопроизводительная визуализация

## Четыре режима приложения

### 1. Synthetic (Создать синтетические данные)
- Генерация синтетических сейсмических данных
- Сохранение в /data/synthetic/ (HDF5 или SEG-Y)
- Параметры: модель среды, источник, шум, кратные волны
- Работает локально (лёгкие вычисления)

### 2. Training (Обучение моделей U-Net)
- Обучение U-Net на синтетических или реальных данных
- Вычисления ТОЛЬКО на удалённом GPU-сервере
- Фоновый процесс — UI остаётся отзывчивым
- Сохранение чекпоинтов в /models/checkpoints/
- Уведомление по завершении поверх всех окон
- Мониторинг: loss и val кривая в реальном времени через WebSocket

### 3. Testing (Тесты)
- Быстрая визуальная проверка качества обученной модели
- Малые выборки данных, лёгкие вычисления
- Цель: принять решение — переходить ли к полной обработке
- Загрузка .pth файла + небольшого HDF5/SEG-Y среза

### 4. Processing (Обработка данных)
- Полная обработка сейсмических данных обученной моделью
- Вычисления на удалённом GPU-сервере
- Загрузка HDF5/SEG-Y + .pth чекпоинта
- Результат сохраняется рядом с исходными данными

## Логика запуска и навигации

### Запуск приложения
Запуск
   │
   ▼
Есть сохранённые проекты?
   │
   ├── НЕТ ──► LaunchScreen (QDialog, модальное окно)
   │            └── Выбор режима → создать вкладку
   │
   └── ДА ───► RecentProjectsDialog
                ├── Выбрать существующий проект
                │   → восстановить с последнего места
                │   → открыть сохранённые вкладки
                │   → без LaunchScreen
                └── Создать новый проект
                    → LaunchScreen (QDialog)

### LaunchScreen
- QDialog — модальное окно поверх MainWindow
- Появляется ТОЛЬКО при:
  1. Первом запуске (нет сохранённых проектов)
  2. Создании нового проекта
- Закрывается (accept) после выбора режима
- НЕ является частью QStackedWidget

### Вкладки режимов
- Максимум 4 вкладки — по одной на каждый режим
- Каждый режим существует строго в одном экземпляре
- Отображаются ТОЛЬКО активированные пользователем
- Создаются lazy — при первом открытии режима
- Если режим уже открыт → просто переключиться на вкладку
- Кнопки ← → навигации: НЕ реализуем
- Закрытие вкладки (×):
  - Если есть несохранённые изменения или активная задача
    → диалог "Сохранить прогресс?"
  - Фоновая задача на сервере продолжается в любом случае
  - Вкладка удаляется из QStackedWidget

### Фоновые задачи
- QThread живёт в AppController, НЕ в виджете режима
- Виджет — только отображение статуса задачи
- Закрытие вкладки НЕ останавливает QThread
- Уведомление о завершении приходит поверх любой вкладки

## Управление проектами
- Кнопка "Сохранить проект" → .json в /data/projects/
- RecentProjectsDialog при повторном запуске
- Максимум 10 проектов в списке recent
- Формат: JSON с путями, параметрами, активными вкладками

## Подключение к серверу
- Поддерживаемые провайдеры: RunPod, Google Colab, Kaggle
- При недоступности: Training и Processing заблокированы
- Synthetic и Testing доступны офлайн
- Статус сервера отображается в toolbar постоянно
- Таймаут ping: 3 секунды

## Поддерживаемые форматы данных
- HDF5 (.h5, .hdf5) — основной формат
- SEG-Y (.segy, .sgy) — полевые данные
